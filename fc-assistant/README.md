# FC 감독모드 이미지 인식 보조 도구

FC온라인 감독모드 진행 중 반복되는 화면 확인·버튼 클릭·경기 종료 후 처리를
**이미지 인식 기반**으로 보조하는 도구입니다.

좌표를 외워서 누르는 매크로가 아니라, **지금 화면이 어떤 상태인지 먼저 판단**하고
확실한 상태에서만 동작하는 안전형 구조입니다. UI가 업데이트되면 코드 수정 없이
템플릿 이미지(PNG)만 교체하면 됩니다.

> ⚠️ **이용 안내**: 개인 테스트/연구 목적의 도구입니다. 게임 약관에 따라
> 자동화 도구 사용이 제한될 수 있으며, 사용 책임은 사용자에게 있습니다.
> 탐지 우회, 보안 프로그램 우회, 메모리/패킷 조작, 무제한 반복 기능은
> 포함하지 않으며 앞으로도 추가하지 않습니다.

## 1. exe 파일 받기 (두 가지 방법)

### 방법 A. GitHub Actions 자동 빌드 (권장, 설치 불필요)
이 저장소에 push하면 GitHub이 Windows 환경에서 exe를 자동으로 빌드합니다.

1. GitHub 저장소 → **Actions** 탭 → **Build FC Assistant Windows EXE** 워크플로 선택
2. 최근 실행(초록 체크) 클릭 → 하단 **Artifacts** 에서 `FCManagerAssistant-win64` 다운로드
3. 압축을 풀면 `FCManagerAssistant.exe` 가 나옵니다

수동으로 다시 빌드하려면 Actions 탭에서 **Run workflow** 버튼을 누르면 됩니다.

### 방법 B. 내 PC에서 직접 빌드
Python 3.10 이상이 설치된 Windows PC에서:

```bat
git clone <이 저장소>
cd Fc-game\fc-assistant
packaging\build.bat
```

빌드가 끝나면 `fc-assistant\dist\FCManagerAssistant.exe` 가 생성됩니다.

> 참고: PyInstaller로 만든 exe는 일부 백신이 오탐하는 경우가 있습니다.
> 직접 빌드한 파일이므로 예외 등록하면 됩니다.

## 2. 첫 실행 - 템플릿 등록 (필수)

이 도구는 **게임 화면 이미지가 있어야 동작**합니다. 배포판에는 저작권/버전 문제로
게임 스크린샷이 포함되어 있지 않으므로, 처음 한 번은 내 해상도 기준으로
템플릿을 등록해야 합니다. 프로그램 안에서 모두 처리할 수 있습니다.

`FCManagerAssistant.exe` 를 처음 실행하면 exe 옆에 폴더가 자동 생성됩니다:

```text
FCManagerAssistant.exe
templates/
  fc_online_2026_07/          ← 템플릿 버전 (UI 기준 날짜)
    manifest.json             ← 상태/ROI 정의 (수정 가능)
    1920x1080/                ← 해상도별 템플릿 폴더
    2560x1440/
    _backup/                  ← 교체 전 이미지 자동 보관
config/user_config.json       ← 설정
logs/                         ← 실행 로그(txt/csv) + 오류 스크린샷
```

### 등록 순서
1. FC온라인을 실행하고 **감독모드 로비** 화면을 띄웁니다
2. 도구의 **[템플릿 관리]** 탭 → **[게임 화면 캡처]** 클릭
3. 목록에서 `btn_start` 선택 → **[영역 선택 → 템플릿 등록]** → 시작 버튼 영역만 드래그 → 저장
4. 같은 화면에서 `state_lobby` (로비에서만 보이는 고유 UI, 예: 좌측 메뉴 타이틀)도 등록
5. 경기 중/결과/보상 팝업 화면에서도 같은 방식으로 등록:

| 템플릿 | 캡처할 것 | 사용 상태 |
| --- | --- | --- |
| `btn_start` | 경기 시작 버튼 | 로비 |
| `state_lobby` | 로비 고유 UI | 로비 |
| `state_matching` | 매칭/로딩 화면 고유 UI | 매칭 중 |
| `state_scoreboard` | 경기 중 상단 스코어보드 | 경기 중 |
| `state_match_time` | 경기 중 시간 표시 | 경기 중 |
| `state_result` | 결과 화면 타이틀 | 경기 종료 |
| `btn_confirm` | 확인/다음 버튼 | 결과·팝업 |
| `popup_reward` | 보상 팝업 프레임(제목 등) | 보상 팝업 |
| `btn_close` | 팝업 닫기(X) 버튼 | 팝업 |
| `popup_error` | 오류/점검 팝업 고유 부분 | 오류 감지 |

6. **[매칭 테스트]** 버튼으로 각 템플릿 인식 점수(0.85 이상 권장)와
   "이 화면 인식 결과"가 올바른지 확인합니다

> 팁: 게임을 켤 수 없는 자리에서는 미리 찍어둔 스크린샷 파일을
> **[이미지 파일 열기]** 로 불러와 같은 작업을 할 수 있습니다.

## 3. 사용 방법

1. FC온라인 실행 → 감독모드 로비까지 수동 진입
2. 도구 **[설정]** 탭에서 반복 횟수 등 확인 → **설정 저장**
3. **[제어판]** 탭 → **▶ 시작 (F9)**
4. 게임 창을 활성 상태(맨 앞)로 두면 자동 진행됩니다

동작 흐름: `로비 → 경기 시작 클릭 → 매칭/로딩 대기 → 경기 중 대기
→ 결과 확인 클릭 → 보상 팝업 처리 → 다시 로비` 를 설정한 횟수만큼 반복.

### 안전 장치 (자동)
| 장치 | 동작 |
| --- | --- |
| 강제 정지 단축키 | **F10** 즉시 정지 (전역, 게임 중에도 동작) |
| 마우스 FAILSAFE | 마우스를 화면 **왼쪽 위 모서리**로 밀면 즉시 중단 |
| 창 비활성 감지 | 게임 창이 맨 앞이 아니면 어떤 입력도 하지 않음 |
| 알 수 없는 화면 | 5초(설정 가능) 이상 상태 판단 실패 시 자동 정지 + 스크린샷 |
| 클릭 전 재확인 | 화면을 다시 캡처해 버튼을 재검증한 뒤에만 클릭 |
| 다중 근거 판정 | 템플릿 1개 일치만으로는 클릭하지 않음 (2개 이상 조합) |
| 반복/시간 제한 | 설정 횟수 도달 또는 최대 실행 시간 초과 시 정지 |
| 오류 팝업 감지 | 즉시 정지(기본) + 스크린샷 저장 |

### 로그
- `logs/run_*.txt` : 사람이 읽는 실행 기록
- `logs/run_*.csv` : 시간/상태/동작/점수 분석용
- `logs/screenshots/` : 오류·알 수 없는 화면 자동 캡처

## 4. UI 업데이트 대응 (템플릿 교체)

게임 UI가 바뀌어 인식이 안 되면:

1. [템플릿 관리]에서 새 화면을 캡처해 해당 템플릿만 다시 등록 (이전 파일은 `_backup/`에 보관)
2. 큰 개편이면 `templates/fc_online_2026_07` 폴더를 복사해
   `fc_online_2027_01` 처럼 새 버전 폴더를 만들고, [설정]에서 버전 선택

ROI(탐색 영역)나 상태 정의를 바꾸고 싶으면 `manifest.json` 을 수정하면 됩니다.
값은 창 크기 대비 비율 `[x, y, w, h]` 입니다.

## 5. 설정 항목

| 항목 | 기본값 | 설명 |
| --- | --- | --- |
| 해상도 프로필 | auto | 창 크기와 같은 템플릿 폴더 자동 선택 |
| 인식 민감도 | 0.85 | 낮추면 잘 찾지만 오탐 위험 증가 |
| 반복 횟수 제한 | 10 | 경기 수 기준, 도달 시 자동 정지 |
| 최대 실행 시간 | 90분 | 초과 시 자동 정지 (장시간 방치 방지) |
| 화면 검사 주기 | 500ms | 낮출수록 반응 빠름/CPU 사용 증가 |
| 오류 시 동작 | 즉시 정지 | 또는 로그만 남기고 대기 |
| OCR 보조 | 끔 | pytesseract 설치 시 오류 문구를 로그에 기록 |

단축키 변경: `config/user_config.json` 의 `hotkey_start` / `hotkey_stop` (F1~F12, ESC).

## 6. 소스 실행 / 개발

```bash
cd fc-assistant
pip install -r requirements.txt
python run_app.py            # GUI 실행 (Windows)
python -m fc_assistant --selftest   # 핵심 로직 테스트 (모든 OS)
```

### 구조
```text
fc_assistant/
  window.py     게임 창 탐색/활성 확인 (Win32)
  capture.py    MSS 화면 캡처
  detector.py   OpenCV 템플릿 매칭 + ROI + 상태 판정
  templates.py  템플릿/manifest/백업 관리
  engine.py     메인 루프 (상태 머신 + 안전 장치)
  actions.py    PyAutoGUI 클릭 (FAILSAFE 켬)
  safety.py     전역 단축키 감시
  logger.py     txt/csv 로그 + 스크린샷
  config.py     JSON 설정
  ocr.py        pytesseract 보조 (선택)
  app.py        Tkinter GUI
  selftest.py   합성 이미지 검증 (CI에서 실행)
```

## 7. 문제 해결

| 증상 | 확인 |
| --- | --- |
| 게임 창을 못 찾음 | [설정]의 창 제목 키워드에 실제 창 제목 일부 추가 |
| 버튼 인식 점수가 낮음 | 같은 해상도·창 모드에서 다시 캡처, 애니메이션 없는 순간 캡처 |
| 자꾸 "알 수 없는 화면" 정지 | 해당 화면 상태 템플릿 미등록 → 템플릿 추가 |
| 클릭 위치가 어긋남 | Windows 배율(DPI) 변경 후 게임/도구 재시작 |
| exe 실행 직후 종료 | `logs/crash_*.txt` 확인 |
