# Asset Credits

이 프로젝트가 사용하는 외부 무료 에셋과 라이선스입니다. 모두 재배포/상업적 사용이 가능한 CC0 또는 OFL 라이선스입니다.

## 텍스처 (Textures)

- **Kenney Prototype Textures**
  - 파일: `assets/textures/wall_dark.png`, `assets/textures/wall_red.png`
  - 원작자: Kenney (kenney.nl)
  - 라이선스: **CC0 1.0 Universal** (퍼블릭 도메인, 출처 표기 불필요)
  - 취득: GitHub 미러 [`Calinou/kenney-prototype-textures`](https://github.com/Calinou/kenney-prototype-textures)
    (`addons/kenney_prototype_textures/{dark,red}/texture_08.png`)

## 폰트 (Fonts)

- **Press Start 2P**
  - 파일: `assets/fonts/PressStart2P.ttf`
  - 원작자: CodeMan38 (The Press Start 2P Project)
  - 라이선스: **SIL Open Font License 1.1** (`assets/fonts/PressStart2P-OFL.txt`)
  - 취득: GitHub [`google/fonts`](https://github.com/google/fonts) (`ofl/pressstart2p`)

## 캐릭터/적 스프라이트 (Characters)

- 현재 적/무기 스프라이트는 **런타임에 Canvas 도형으로 절차적 생성** (원본, 라이선스 제약 없음).
  `game.js`의 `buildSprites()`에서 정의하며, 원하는 CC0 스프라이트 PNG로 손쉽게 교체할 수 있습니다.
